# Changelog

## 1.1.0 - 2026-10-30

- Store prerequisite courses in a normalised plugin table.
- Preserve prerequisite configuration during same-site course backup and restore.
- Disable restored instances from another site until prerequisites are reconfigured.
- Remove references automatically when a prerequisite course is deleted.
- Add a dedicated plugin icon and publication documentation.
- Use isolated, responsive enrolment notices to avoid theme layout conflicts.

## 1.0.0 - 2026-10-30

- First stable release for Moodle 4.5.1+.
- Support one or more prerequisite courses with **any** or **all** matching.
- Require active, current, non-suspended enrolments.
- Add enrolment instructions, availability dates, duration, capacity and welcome messages.
- Display an enrolment information icon in course listings supported by the active theme.
